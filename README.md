# Prototype 0

Premier essai technique du jeu d'arène 1 contre 1 en vue 2,5D.

## Version actuelle

- arène 3D plus grande que l'écran ;
- caméra inclinée suivant le joueur avec anticipation de la visée ;
- déplacement clavier AZERTY/QWERTY et flèches ;
- tir à la souris ou avec la barre d'espace ;
- obstacles bloquant le joueur et les projectiles ;
- cible d'entraînement avec points de vie et réinitialisation.

Les formes et couleurs sont provisoires. Cette version sert à valider la perspective, la caméra, les déplacements et les collisions avant l'intégration des véritables armes et modules.

## Lancer le prototype

Ouvrir `project.godot` avec Godot 4.7.2, puis appuyer sur `F6` ou `F5`.

## Commandes

- `ZQSD`, `WASD` ou flèches : déplacement ;
- souris : viser ;
- clic gauche ou espace : tirer.
