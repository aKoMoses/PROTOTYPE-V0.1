# Éclipse — une seule proposition

À la demande de l'utilisateur, une seule proposition Stable Audio : l'explosion à l'arrivée. Impact physique lourd et court, puis dispersion rugueuse de particules, sans signal aigu de téléportation.

Le son est à écouter avant validation. Aucune intégration au jeu n'est réalisée à ce stade.

Source complète dans raw ; grain préparé dans candidates. Le manifeste conserve l'intervalle, les niveaux et les SHA256. Les vérifications techniques sont dans reports et ne constituent pas une validation esthétique.
